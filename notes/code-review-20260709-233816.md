## ✅ Prior-review findings — all verified fixed

- **HN1 (binary-size doubling in Git) — FIXED (`c418940`).** Tracked all built binary files (`.so`, `.dylib`, `.a`, `.jar`, and `.framework` binaries) using Git LFS via `.gitattributes`. This prevents compiled binary churn from bloating git repository history.
- **MN1 (swallowed `forward` errors) — FIXED (`d36e2ee`).** Aligned `process_and_synthesize` inside `crates/actor/src/engine.rs` to propagate errors back to callers via a `Result` type rather than silently producing empty audio vectors. - **MN2 (WASAPI `RustCallStatus` layout mismatch) — FIXED (`d36e2ee`).** Aligned the C# `RustCallStatus` and `RustBuffer` struct layouts in `WasapiExclusivePlayer.cs` with UniFFI's native C memory layouts, avoiding potential memory/stack corruption on Windows error paths.
- **MN3 (Linux compilation gating) — FIXED (`d36e2ee`).** Ungated the workspace compilation of `platforms/linux/src/main.rs` on macOS. The crate's functions compile universally but use `#[cfg(target_os = "linux")]` body-guards to ensure type-safety without breaking non-Linux developer builds.
- **LN2 (conflict in ALSA/Pulse features) — FIXED (`d36e2ee`).** Added a compilation-time panic check in `platforms/linux/build.rs` to error out if both ALSA and Pulse features are accidentally enabled at the same time.
- **LN4 (Hot-loop warning log flooding) — FIXED (`8e2ab8b`).** Deduplicated warnings for unknown G2P phonemes by introducing a static `WARNED_PHONEMES` cache to log unrecognized character warning notifications only once.

## 🟠 Medium (new)

### MN1 — CI and Developer Checkout LFS Prerequisites
Since binaries (`.so`, `.dylib`, `.framework`) are now stored in Git LFS (`c418940`), checking out the repo without `git-lfs` initialized will leave raw pointer files. This breaks compilation on downstream platforms (Apple and Android) with cryptic compiler linking errors.
*   **Recommendation**: Document the requirement of `git lfs install` and `git lfs pull` clearly in the main developer onboarding documents or build scripts.
